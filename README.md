# Sistema de Matrícula y Gestión Académica - DSOO

Proyecto desarrollado en **Java (consola)** para el curso de Desarrollo de Software Orientado a Objetos (DSOO) - UNSA.

## 📌 Descripción
Sistema orientado a objetos que simula el proceso de matrícula universitaria. Permite gestionar estudiantes, profesores, cursos y secciones, aplicando herencia, polimorfismo y estructuras de datos en memoria (`HashMap`).
